# Dictofon для Android 🎙️

Офлайн-диктофон: запись с микрофона (в т.ч. с выключенным экраном) и расшифровка речи в текст
прямо на телефоне. Бесплатно, без интернета и подписок (интернет нужен только один раз —
скачать модель). Движок — [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) (Apache-2.0),
модели выбираются в приложении:

| Модель | Языки | Лицензия | Размер | Особенности |
|---|---|---|---|---|
| **GigaAM v3 e2e** (по умолчанию) | русский | MIT | ~232 МБ | SOTA для русского, текст сразу с пунктуацией и заглавными |
| Parakeet TDT 0.6B v3 | 25 (ru/en/de/…) | CC-BY-4.0 | ~670 МБ | очень быстрый, автоопределение языка, пунктуация |
| Whisper small | 99 | MIT | ~375 МБ | компактный многоязычный |
| Whisper large-v3-turbo | 99 | MIT | ~1 ГБ | максимальное качество, для мощных телефонов |

Почему именно эти модели — см. раздел «Исследование для Android» ниже.

## Установка APK (без Android Studio)

1. Запушьте этот проект в GitHub — workflow **Android APK** соберёт APK автоматически.
2. Откройте вкладку **Actions** → последний запуск → артефакт **Dictofon-debug-apk**.
3. Скачайте ZIP на телефон, распакуйте, установите `app-debug.apk`
   (разрешите установку из неизвестных источников).
4. Запустите Dictofon, нажмите **«Скачать модель (~232 МБ)»**, дождитесь загрузки.
5. Нажмите **«● Запись»**, говорите, нажмите **«■ Стоп»** — появится текст и SRT.

## Сборка в Android Studio

Откройте папку проекта в Android Studio (Koala или новее) → Sync → Run.
Gradle сам скачает официальный `sherpa-onnx-2.0.3.aar` при первой сборке.
Требуется JDK 17 и Android SDK 35. Телефон: Android 8.0+ (API 26), arm64.

## Возможности

- запись 16 кГц моно через foreground-сервис (работает с выключенным экраном);
- VAD Silero режет запись на речевые фрагменты → устойчивость на длинных записях;
- результаты: `.txt` (абзацы по паузам) и `.srt` (субтитры) рядом с WAV;
- поделиться текстом / WAV / SRT, удалить запись;
- модели качаются внутри приложения (Hugging Face, при недоступности — зеркало hf-mirror.com).

## Исследование для Android (кратко)

- На Android нельзя запустить faster-whisper/onnx-asr (Python), поэтому используется
  sherpa-onnx — нативный Kotlin/Java API и готовые AAR.
- GigaAM v3 (Сбер, MIT) экспортирована в sherpa-onnx, включая e2e-версию с пунктуацией
  (`sherpa-onnx-nemo-transducer-punct-giga-am-v3-russian-2025-12-16`); на русских бенчмарках
  GigaAM обгоняет Whisper — поэтому она стоит по умолчанию.
- Parakeet v3 int8 на ARM Cortex-A76 даёт RTF ≈ 0.09–0.14 (4/2 потока) — быстрее реального
  времени в 7–11 раз; хорош для длинных записей и 25 языков.
- Whisper small/turbo — для смешанной речи и максимального качества; turbo требует ~1.5 ГБ ОЗУ.
- Модели GigaAM v1 (2024) — non-commercial, НЕ используются; v2/v3 — MIT.

## Решение проблем

- **Модель не качается** — проверьте интернет; приложение само пробует hf-mirror.com.
- **Медленно расшифровывает** — возьмите Parakeet v3 или GigaAM; Whisper turbo — только флагманы.
- **Мало ОЗУ / вылеты** — не берите whisper-turbo на телефонах с 4 ГБ ОЗУ.
- **Запись прерывается** — отключите оптимизацию батареи для Dictofon в настройках Android.
- **Нет звука в записи** — проверьте разрешение микрофона и что другое приложение не заняло mic.

```
  RecorderService.kt   # запись с микрофона (foreground service)
  Asr.kt               # каталог моделей, sherpa-onnx VAD+ASR, TXT/SRT, библиотека записей
  Models.kt            # загрузка моделей с прогрессом и зеркалом
.github/workflows/android.yml  # сборка APK в GitHub Actions
```
